# Integration Verification Matrix

Standing rule: every external dependency is verified against primary sources (specs, source code, official docs, release pages) before it is treated as committed architecture. Marketing pages and grant listings are not evidence of a working integration. "Verified" means the stated fact was confirmed in a primary source on the date shown. It does not mean Halora has run it end to end; that column is separate.

Date checked for every row: **2026-10-16** unless noted.

## Status legend

- **Verified:** confirmed in a primary source.
- **Partly verified:** the core fact is confirmed, a detail that matters to Halora is not.
- **Unverified:** only secondary sources, or not found.
- **E2E:** whether Halora has exercised it end to end (all "Not yet" at kickoff).
